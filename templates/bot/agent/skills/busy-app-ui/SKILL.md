# The Busy app: real paths only

This is a map of the Busy hub interface checked against its code. Give the user only paths listed here. If what they ask for isn't here, say you're not sure where it is rather than guessing a menu, button or setting. Labels below are the exact on-screen words.

## Layout

- **Sidebar** (left): "Your bots" lists the bots; a "Create bot" button adds one. The sidebar can be collapsed and expanded with its toggle ("Collapse sidebar" / "Expand sidebar"). On a phone it opens from the menu button in the chat header.
- **Chat** (center): the selected bot's conversation. The header shows the bot's avatar and name and a **Bot settings** button (sliders icon) on the right. Files can be dragged onto the chat to send them to the bot.
- **Bottom of the sidebar**: the account button (avatar and name) and, next to it, a grid-plus button labeled **Skills, plugins and MCPs**.

## Account menu and Settings

- Click the account button at the bottom of the sidebar. The menu has the AI connection entry, **Settings**, and the sign-out item.
- **Settings** has these tabs: **Model**, **Skills**, **Plugins**, **MCPs**, **Usage**.
  - Model: the AI provider and model.
  - Skills: skills installed for the Busy app, including skills saved from chat; each can be enabled, disabled or removed. The built-in `find-skills` is listed here too.
  - Plugins: installed plugins.
  - MCPs: connected apps.
  - Usage: usage information.
- Skills, plugins and connected apps are shared by every bot in the app. There is no per-bot assignment.

## Connecting apps (MCP)

- The **Skills, plugins and MCPs** button at the bottom of the sidebar opens **Your toolbox**, with the user's **Connected apps** and the **Integrations** catalog (filterable).
- Each app card shows **Connect** (or **Connect with OAuth**, or **Add**), **Connected**, or **Connection needs attention**. A connected app can be disconnected with **Disconnect**. Some apps ask for credentials before connecting.
- If an app needs reconnecting, point the user here.

## Bot settings (per bot)

Open the bot's chat, then the **Bot settings** button in the chat header. The panel is titled "<bot name> settings" and has these tabs:

- **General**: name, identity and description; **Save changes**. **Delete bot** is at the bottom: it asks "Delete <name> for good?" and needs a second click. Deleting is permanent.
- **Live**: the bot's computer screen, live (available only while the bot is ready). **Take control** lets the user use the mouse and keyboard on it; **Done logging in** hands control back after a login. A "Mode" control and "Type on the computer" help with typing, including on a phone.
- **Library**: files in the chat, filterable by **All files**, **Generated by bot**, **Sent by me**, each with a download button.
- **Routines**: the bot's routines. Each row's options menu has **Edit**, **Pause** / **Resume**, and **Delete** (with a "Delete routine?" confirmation). New routines are created by asking the bot in chat.
- **Memory**: what the bot remembers; the user can add a memory (**Add memory**) or delete one.
- **History**: search through earlier messages of this chat.

## Logins and taking control from the chat

When the bot asks the user to log in, a card appears in the chat with **Take control** and **Done**. Take control opens the live screen; after logging in, the user taps **Done logging in** in the live view (or **Done** on the card). The card then says "You logged in. It goes on from there."

## Organizing bots

- Right-click in the bot list to **Create section**; right-click a section header to **Rename section** or **Delete section**. Bots are dragged into sections ("Drop bots here.").
- There is no hide or archive for a bot. Removing one means **Delete bot** in its General tab.

## Not in the app

These don't exist in the hub; don't send the user looking for them: a button to reset or restart the bot's computer, a per-bot capabilities list, a form to create routines, keyboard shortcuts for settings. If the user needs one of these, say it isn't available in the app.
